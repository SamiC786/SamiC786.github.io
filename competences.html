Mes compétences

Les outils que j'utilise au quotidien. Le détail des compétences du référentiel BTS SIO est dans le tableau de synthèse.

Visual Studio Code

Éditeur de code puissant que j'utilise pour le développement web et backend, notamment avec HTML, CSS, PHP, et JavaScript.

PyCharm

IDE dédié à Python que j’utilise pour coder plus efficacement avec de l’autocomplétion, du debug, et une bonne organisation de projet.

Postman

Outil utilisé pour tester des API REST, vérifier les réponses JSON, et faire du debug d’interfaces entre front-end et back-end.

Sublime Text

Éditeur de texte léger que j’utilise pour des modifications rapides et des tests rapides de scripts ou pages HTML/CSS.

Pack Office

Je maîtrise Word, Excel et PowerPoint pour la rédaction de rapports, la création de présentations professionnelles et la gestion de données.
