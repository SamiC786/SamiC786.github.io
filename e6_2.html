Ricosheep — Jeu Python

Réalisation en entreprise — 02

Présentation du projet

Ricosheep est un jeu développé en Python dans le cadre de la formation BTS SIO. Le joueur contrôle un mouton qui se déplace et rebondit dans un environnement. Ce projet avait pour objectif de mettre en pratique les bases de la programmation Python dans un contexte ludique et interactif.

Mécaniques du jeu

  • Déplacement du personnage (mouton)
  • Gestion des collisions avec les bords et obstacles
  • Système de score
  • Boucle de jeu principale (game loop)
  • Affichage graphique

Technologies utilisées

Python 3 Tkinter PyCharm

Interface graphique réalisée avec la bibliothèque Tkinter, intégrée nativement dans Python.

Concepts appliqués

  • Programmation Orientée Objet (classes, héritage)
  • Gestion des événements clavier
  • Logique de collision et détection
  • Boucle principale avec gestion du temps
  • Affichage et rafraîchissement de l'écran

Réalisations

  • Conception et développement complet du jeu
  • Implémentation de la logique de jeu
  • Gestion des niveaux et de la difficulté
  • Tests et débogage

Compétences acquises

  • Application de la POO en Python
  • Gestion d'une interface graphique
  • Résolution de problèmes algorithmiques
  • Structuration d'un projet Python
