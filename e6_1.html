Apprentissage Python

Réalisation en entreprise — 01

Contexte

Dans le cadre du BTS SIO, j'ai débuté l'apprentissage du langage Python afin de maîtriser la programmation côté backend. Python est un langage polyvalent, lisible et largement utilisé dans les domaines du développement web, de l'automatisation et de la data science.

Objectifs

  • Comprendre la syntaxe de base de Python
  • Maîtriser les structures de contrôle (if, for, while)
  • Manipuler les types de données (listes, dictionnaires, tuples)
  • Appliquer les principes de la Programmation Orientée Objet
  • Écrire des scripts d'automatisation

Technologies utilisées

Python 3 PyCharm VS Code pip

Environnement de développement local avec PyCharm et gestion des dépendances via pip.

Notions abordées

  • Variables, types et opérateurs
  • Fonctions et paramètres
  • Listes, dictionnaires, sets
  • Gestion des fichiers (lecture/écriture)
  • Classes et objets (POO)
  • Gestion des exceptions (try/except)
  • Modules et bibliothèques

Réalisations

  • Exercices de base et algorithmes simples
  • Scripts d'automatisation de tâches
  • Mini-projets : calculatrice, gestion de listes, etc.
  • Préparation au projet Ricosheep

Compétences acquises

  • Maîtrise de la syntaxe Python
  • Capacité à structurer un programme en modules
  • Raisonnement algorithmique
  • Débogage et lecture de documentation
