Line Watcher — Migration Backend C#

E5 — Réalisation 3

Contexte

Après le développement initial du backend de Line Watcher en Python, une migration vers C# a été entreprise chez Upper Link. Cette décision vise à aligner la stack technique de l'application avec les standards de l'entreprise, à améliorer les performances et à faciliter la maintenance à long terme avec ASP.NET Core.

Objectifs de la migration

  • Réécrire l'API REST en C# avec ASP.NET Core
  • Conserver le comportement fonctionnel existant
  • Améliorer les performances et la robustesse
  • Aligner la stack avec les standards Upper Link
  • Faciliter la maintenance future

Technologies utilisées

C# ASP.NET Core .NET HttpClient Visual Studio NuGet

Étapes de la migration

  • Analyse du backend Python existant
  • Création du projet ASP.NET Core
  • Réécriture des controllers et services
  • Migration de la logique d'appel API IDFM
  • Tests de non-régression
  • Validation et mise en production

Points clés

  • Équivalence fonctionnelle Python → C# garantie
  • Architecture en couches (Controller / Service / Model)
  • Typage fort de C# vs typage dynamique Python
  • Gestion asynchrone avec async/await en C#

Compétences acquises

  • Développement backend en C# / ASP.NET Core
  • Migration technologique d'une application
  • Architecture REST en .NET
  • Gestion de projet de migration
  • Tests de régression
