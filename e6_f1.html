Création d'un Site Web (Portfolio)

Réalisation en formation — F01

Contexte

Dans le cadre du BTS SIO, j'ai conçu et développé un portfolio personnel en HTML et CSS. Ce site a pour objectif de présenter mon parcours, mes compétences, mes projets professionnels (E6) et les situations d'entreprise (E5). Il constitue également un support de présentation lors des épreuves du BTS.

Objectifs

  • Maîtriser la structure HTML5 sémantique
  • Créer une interface responsive avec CSS3
  • Mettre en place une navigation multi-niveaux (dropdown)
  • Organiser le contenu de façon claire et professionnelle
  • Présenter les sections E5 et E6 du BTS SIO

Technologies utilisées

HTML5 CSS3 VS Code

Site statique 100 % HTML/CSS, sans framework ni bibliothèque JavaScript externe.

Réalisations

  • Navigation avec menus déroulants CSS (hover)
  • Design en dark theme (#000, #00bfff)
  • Pages : Accueil, Profil, Parcours, Formation, E5, E6, Veille, CV, Contact
  • Tableau de synthèse E5 avec deux sections distinctes
  • 7 pages détaillées pour les projets professionnels E6
  • Intégration d'un PDF de veille technologique via iframe

Compétences acquises

  • Structuration et organisation d'un projet web statique
  • Maîtrise des sélecteurs et propriétés CSS avancés
  • Mise en page avec Flexbox et Grid
  • Intégration de fichiers PDF et Excel
  • Respect d'une charte graphique cohérente

Difficultés rencontrées

  • Gestion de la cohérence du menu sur toutes les pages
  • Adaptation du contenu pour différentes tailles d'écran
  • Organisation de la navigation entre les sections E5 et E6
