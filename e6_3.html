Apprentissage Angular

Réalisation en entreprise — 03

Contexte

Angular est un framework frontend développé par Google, basé sur TypeScript. Son apprentissage a été nécessaire pour le développement du frontend de l'application Line Watcher chez Upper Link. Il permet de créer des applications web dynamiques et maintenables grâce à son architecture en composants.

Objectifs

  • Comprendre l'architecture d'une application Angular
  • Créer et gérer des composants
  • Utiliser les services pour la logique métier
  • Mettre en place le routing entre les pages
  • Consommer une API REST depuis Angular
  • Maîtriser les directives et pipes Angular

Technologies utilisées

Angular TypeScript HTML/CSS Node.js npm VS Code

Notions abordées

  • Components, Templates et Data Binding
  • Services et injection de dépendances
  • RouterModule et navigation
  • HttpClient pour les appels API
  • Directives (*ngIf, *ngFor)
  • Pipes (date, currency, async)
  • Modules et lazy loading

Réalisations

  • Création de composants réutilisables
  • Mise en place d'un service de données
  • Intégration avec une API REST
  • Application des acquis sur le projet Line Watcher

Compétences acquises

  • Développement frontend avec Angular
  • Utilisation de TypeScript
  • Architecture MVC côté frontend
  • Consommation d'API REST
  • Gestion de l'état applicatif
